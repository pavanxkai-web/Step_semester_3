Java Coding Assignment Solutions
=================================

Files:
1. ExamScoreBandCounter.java
2. SecondBestScore.java
3. ClassAttendanceTracker.java
4. BusiestBusRow.java
5. DutyRosterRotation.java

Each file contains its own public class and main() method for testing.
Compile and run one file at a time from this folder.

Example:
    javac ExamScoreBandCounter.java
    java ExamScoreBandCounter

Complexities:
- ExamScoreBandCounter: O(log n) time, O(1) extra space.
- SecondBestScore: O(n) time, O(1) extra space.
- ClassAttendanceTracker: O(n) time, O(1) extra space.
- BusiestBusRow: O(r * c) time, O(1) extra space (excluding result array).
- DutyRosterRotation: O(n) time, O(n) extra space.
